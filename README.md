# Terra — Good skin. Good mood.

> Everyday skincare essentials, clean biocompatible botanicals, and a feel-good daily ritual.

---

## 🌸 Project Overview
A complete, high-craft skincare concept store and daily routine experience. Designed with balanced, human-scale proportions, warm pastel aesthetics, and smooth scroll motion powered by **Motion.dev**.

### ✨ Key Features & Improvements
- **Proportional Rescaling**: Rebalanced hero layout (`520px` max), clamped typography (`clamp(42px, 5.2vw, 68px)`), and human-proportioned editorial grids that eliminate towering empty spaces.
- **Motion.dev Scroll Motion**:
  - Dynamic top scroll-progress indicator (`Motion.scroll`).
  - Scroll-linked parallax transforms on hero campaign artwork, rotating sunbursts, and floating sticker badges.
  - Viewport-triggered staggered card reveals (`Motion.inView`, `Motion.stagger`).
  - Spring-driven button physics and micro-interactions.
- **Rich Content & Discovery**:
  - **Brand Assurance Strip**: Clean proof badges (100% Vegan, Leaping Bunny Certified, Dermatologist Approved, Recyclable Glass).
  - **Clean Ingredients Spotlight**: Detailed breakdown of Centella Asiatica, Olive Squalane, 3% Niacinamide, and Marshmallow Root.
  - **Interactive AM / PM Routine Explorer**: Toggle between Morning Glow and Evening Calm rituals with step-by-step guidance and pro tips.
  - **Community Love & Reviews**: Verified customer experiences with skin-type chips and star ratings.
  - **Interactive FAQ Accordion**: Collapsible answers for ingredient sensitivities, retinol layering, and routine lifespans.
  - **Interactive Shopping Bag Drawer**: Slide-out cart with live subtotal calculation, item removal, and spring toast notifications.
  - **Feel-Good Club**: Newsletter sign-up with instant coupon confirmation.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally:

```bash
# Python 3
python -m http.server 8000

# or Node.js
npx serve .
```

Visit `http://localhost:8000` to preview the site.
