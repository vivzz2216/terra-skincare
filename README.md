# Terra — Good skin. Good mood.

Static responsive homepage. No dependency installation or build step.

From the parent websites directory: `python -m http.server 8765`, then visit http://localhost:8765/test2/.

Navigation and routine links work locally. This is a concept store, without checkout. Product names/prices follow the supplied reference; no clinical claims or testimonials are invented.

## Assets
`assets/campaign.webp`, `assets/products.webp`, `assets/morning.webp` were created with the built-in ImageGen tool, then converted to WebP. Exact generation briefs are in `assets/PROVENANCE.md`. The reference was supplied by the user. Fonts load from Google Fonts, with local fallbacks.
